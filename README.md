# Berthama

A responsive client-facing website built with vanilla JavaScript, HTML, and CSS.

**Live Site:** https://berthama.vercel.app/

## Overview

Berthama is a responsive web application built as a client-facing website with an emphasis on clean presentation, responsive design, and interactive navigation.

The project was developed from the ground up and deployed as a live web application.

## Features

* Responsive design for desktop and mobile devices
* Interactive client-side navigation
* Animated page transitions
* Landing, About, Releases, and Contact sections
* Embedded Spotify content
* Custom styling and layout
* Responsive media and typography
* Production deployment through Vercel

## Technologies

* HTML5
* CSS3
* JavaScript
* Vercel

## Project Structure

```text
berthama/
├── index.html
├── script.js
├── styles.css
├── berthama.png
└── berthamapreview.jpeg
```

### `index.html`

Contains the main application structure, navigation, content sections, metadata, and embedded media.

### `script.js`

Handles client-side navigation, page transitions, and interactive behavior.

### `styles.css`

Contains the application's responsive layout, typography, animations, and visual styling.

## Development

The project was built using standard web technologies without a frontend framework.

The application uses JavaScript to manage navigation and transitions while CSS handles the responsive presentation and visual effects.

## Deployment

The application is deployed using Vercel and is available at:

**https://berthama.vercel.app/**

## Purpose

This project demonstrates experience building responsive client-facing websites from the ground up, including frontend structure, styling, JavaScript interactions, third-party content integration, and deployment.
